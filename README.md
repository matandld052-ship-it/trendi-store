# trendi — אב-טיפוס לחנות אונליין בעברית

זהו אב-טיפוס סטטי עם עיצוב רספונסיבי, כיוון RTL, כרטיסי מוצר ועגלת קניות מקומית להדגמה.

## איך מפעילים
1. חלצו את קובץ ה-ZIP.
2. פתחו את `index.html` בדפדפן במחשב או בטלפון.
3. אפשר ללחוץ על "הוספה לעגלה" כדי לבדוק את הדגמת העגלה.

## מה עדיין לא עובד / לא קיים
- אין סליקת אשראי, Bit או העברה בנקאית מחוברת.
- אין הזמנות אמיתיות, מלאי, משתמשים, מסד נתונים או מערכת ניהול.
- שמות המוצרים, המחירים והאיורים הם דוגמאות בלבד ולא הצעות מכירה מאומתות.
- העגלה נשמרת בזיכרון הדפדפן בלבד ונעלמת ברענון.
- אין לפרסם את האתר כמוכן למכירה לפני שמוסיפים תנאי שימוש, פרטיות, מדיניות משלוחים/החזרות, פרטי עסק ובדיקות תשלום.

## איך לפרסם בחינם
אפשר להעלות את הקבצים לשירות אירוח סטטי עם תוכנית חינמית, למשל GitHub Pages, לאחר יצירת חשבון והגדרת מאגר ציבורי. הכתובת תהיה תת-דומיין של השירות. זמינות ותנאי התוכנית עשויים להשתנות. לא בוצעה כאן העלאה לאינטרנט, ולכן האתר כרגע מקומי בלבד.

## לפני שמקבלים תשלומים בישראל
1. לבחור ספק סליקה/תשלום עסקי ולבדוק זכאות, עמלות ותנאים עדכניים.
2. עבור העברה בנקאית: להציג פרטי תשלום באופן מאובטח ולאשר תשלום רק לאחר בדיקה בפועל.
3. עבור Bit: לא להציג כאילו יש אינטגרציה אוטומטית; צריך לבדוק אפשרות עסקית רשמית ודרך אינטגרציה נתמכת.
4. להוסיף צד שרת מאובטח, אימות תשלום, אחסון הזמנות, הגנה על מידע, והודעות ללקוח.
5. לבדוק חובות רישום, מס, גיל/הרשאה, צרכנות ופרטיות לפני פעילות מסחרית.
